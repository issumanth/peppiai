# peppiai# Peppi 🐻

Peppi is an AI-powered emotional well-being and self-development companion.

## Vision

Peppi is designed to provide a safe, personalized space where users can:

- Explore their emotions and personal patterns
- Talk with an AI companion
- Build and track skills
- Discover healthy, finite content
- Receive personalized recommendations
- Customize their AI experience

## Core Features

### 🪞 Self Explore
Situational questions and reflections that help users understand their emotional patterns.

### 🐻 AI Companion
A personalized AI chatbot with context, memory, multilingual support, and voice interaction.

### 🌱 Skills
Users can choose skills they want to develop and track their progress with AI assistance.

### 👤 Profile
A personal "My Journey" dashboard containing well-being indicators, skill progress, preferences, and privacy controls.

## Technology Stack

- Frontend: React Native + Expo + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL + Supabase
- AI/ML: Python + LLM APIs
- Authentication: Supabase Auth
